# CopyTyGo v4 Roadmap

CopyTyGo v4 is the feature-complete framework milestone. It combines a mature backend ecosystem with first-class developer experience.

## Developer Experience

- Default welcome page
- CopyTyGo Studio
- Route explorer
- Resource and model inspector
- Database and migration manager
- Request, error and log inspection
- Visual generators
- Doctor dashboard
- Interactive project installer
- Documentation integration
- Production-safe Studio controls

## Backend Ecosystem

- Queue and background workers
- Scheduler
- Cache abstraction
- Mail
- Storage and uploads
- Events and listeners
- Database transactions
- Model relationships
- Seeders and factories
- API resources and serialization
- Sessions and cookies
- Authorization and policy improvements
- Rate limiting
- Testing helpers and fakes
- Retry and backoff
- Health and observability improvements

## Release rule

v4 should be usable for real application development. v5 is reserved for stabilization, public documentation, examples, distribution polish and public launch.
